Antigravity IDE • Digital Twin SDK & Event Stream

Control this Digital Twin programmatically from the Antigravity IDE, external dashboards, or parent iframes using window.JumeirahTwinAPI or window.postMessage.

SDK & Iframe Protocol:
// 1. Switch between 'render' and 'site' (or 'shoring')
window.JumeirahTwinAPI.setSiteState('site');

// 2. Smoothly fly camera ('frontRender' | 'rearPool' | 'rearShoring' | 'frontYardTop' | 'carport'):
window.JumeirahTwinAPI.setCameraView('rearPool');

// 3. Set Lighting Mode ('day' | 'dusk' | 'night'):
window.JumeirahTwinAPI.setEnvironment('dusk');

// 4. Or via iframe postMessage from parent dashboard:
iframeRef.contentWindow.postMessage({
  type: 'TWIN_COMMAND',
  action: 'SET_STATE',
  payload: 'site'
}, '*');
